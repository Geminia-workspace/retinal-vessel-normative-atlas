# REVEAL 2.0 Windows Demo

Download both parts of the archive from the [GitHub Release](https://github.com/Geminia-workspace/retinal-vessel-normative-atlas/releases/tag/v2.0-demo):

- `reveal_2.0.zip.001`
- `reveal_2.0.zip.002`

## Extract and run

1. Save both files in the same directory, without renaming them. Make sure both downloads have completed before extracting.
2. In 7-Zip, open `reveal_2.0.zip.001` and extract the archive. 7-Zip reads `.002` automatically. Do not extract the second part separately.
3. In the extracted directory, keep `REVEAL 2.0.exe` and the `VesselAnalysis` folder side by side. Launch the executable from that directory.

```text
Extracted directory/
  REVEAL 2.0.exe
  VesselAnalysis/
```

Do not move the executable away from the `VesselAnalysis` folder. This demo includes the Windows executable and its accompanying files; application source code and study datasets are not included.
